# Application Module Listener

트랜잭션 이벤트 리스너 자체를 트랜잭션 안에서 실행하려면, 리스너 메서드에도 `@Transactional`을 붙여야 해요.

자기 자신도 트랜잭션 안에서 실행되는 비동기 트랜잭션 이벤트 리스너

- Java

- Kotlin

```java
@Component
class InventoryManagement {

  @Async
  @Transactional(propagation = Propagation.REQUIRES_NEW)
  @TransactionalEventListener
  void on(OrderCompleted event) { /* … */ }
}
```

이 방식은 동작은 명확하지만 매번 선언해야 하는 애노테이션이 많아요. Spring Modulith는 이벤트를 통한 모듈 통합의 기본 방식을 더 쉽게 선언할 수 있도록 `@ApplicationModuleListener`를 제공해요.

애플리케이션 모듈 리스너

- Java

- Kotlin

```java
@Component
class InventoryManagement {

  @ApplicationModuleListener
  void on(OrderCompleted event) { /* … */ }
}
```

`@ApplicationModuleListener`는 비동기 처리, 트랜잭션 커밋 이후 실행, 새 트랜잭션에서의 리스너 실행이라는 의도를 간결하게 드러내요. 즉 모듈 간 통합 이벤트를 처리할 때 반복적으로 필요한 설정을 하나의 의미 있는 애노테이션으로 표현할 수 있어요.
