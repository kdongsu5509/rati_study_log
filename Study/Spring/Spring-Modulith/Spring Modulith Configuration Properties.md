# Spring Modulith Configuration Properties

Spring Modulith 공식 문서의 설정 프로퍼티 부록이에요.

이 문서는 `spring.modulith.*`로 시작하는 설정 값들의 이름, 기본값, 의미를 확인할 때 참고해요. 예를 들어 이벤트 발행 레지스트리, 테스트 최적화, 런타임 검증, Flyway 연동 같은 기능의 세부 동작을 프로퍼티로 조정할 수 있어요.
