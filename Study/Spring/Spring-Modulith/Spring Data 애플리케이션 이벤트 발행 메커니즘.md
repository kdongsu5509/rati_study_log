# Spring Data 애플리케이션 이벤트 발행 메커니즘

Spring Data repositories가 aggregate root에서 도메인 이벤트를 수집하고 발행하는 기능을 설명하는 문서예요. Spring Modulith의 `ApplicationEventPublisher` 직접 사용보다 aggregate 중심으로 이벤트를 드러내고 싶을 때 참고하면 좋아요.
