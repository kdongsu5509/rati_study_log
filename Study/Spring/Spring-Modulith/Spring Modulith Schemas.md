# Spring Modulith Schemas

Spring Modulith 공식 문서의 스키마 부록이에요.

이 문서는 이벤트 발행 레지스트리에서 사용하는 테이블, 컬렉션, 노드 같은 저장소 스키마를 확인할 때 참고해요. Flyway나 Liquibase 같은 마이그레이션 도구로 스키마를 직접 관리해야 하는 경우 유용해요.
